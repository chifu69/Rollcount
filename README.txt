ROLL COUNT PWA

Files: index.html, styles.css, app.js, manifest.webmanifest, sw.js, icons.

Features:
- Mobile-first roll counting
- Area 1 / Area 2 / Line / Other per roll type
- Automatic totals
- Inventory Summary shows only rolls in stock
- Share Report via iPhone Share Sheet
- Copy report
- PDF/Print
- New Day / Clear with confirmation
- Automatic history before clearing
- Offline support after first load
- Saves current count locally on the iPhone

INSTALL ON IPHONE
1. Host this folder on any HTTPS static website host.
2. Open the URL in Safari.
3. Share > Add to Home Screen > Open as Web App / Add.

GitHub is NOT required. Any HTTPS static host works.
